# 串口协议

设备通过 **USART1（9600 8N1）** 接收命令，每一帧固定 **12 字节**：

```
FF │ 10 字节有效数据 │ FE
```

| 位置 | 含义 |
|---|---|
| `FF` | 帧头 |
| `0…9` | 有效数据（10 字节），`[0]` 是命令类型 |
| `FE` | 帧尾 |

固件用状态机收包：见到 `FF` 开始、收满 10 字节、再见到 `FE` 才算一帧有效。中途包尾不对则整帧丢弃、状态归零。

> **回显（ACK）**：一帧处理完后，固件把这 10 字节原样再发回去（同样加 `FF`/`FE`）。上位机可以用它确认"这一帧执行完了"。

## 一、命令类型

| `[0]` | 命令 | 说明 |
|---|---|---|
| `0x00` | 空操作 | 保留（可用于占位/延时，由上位机控制节奏时用） |
| `0x01` | 键盘 | 发一次键盘 HID 报告 |
| `0x02` | 鼠标 | 发一次鼠标 HID 报告 |
| `0x03` | 蜂鸣器 | 响 30 ms，并翻转 LED |

## 二、键盘帧（`0x01`）

| 字节 | 含义 |
|---|---|
| `[0]` | `0x01` |
| `[1]` | 修饰键位图（见下表） |
| `[2]` | **按住时长**，单位 10 ms（`0` = 按住不放，不自动抬起） |
| `[3]`–`[8]` | 最多 6 个 HID 键码（同时按下），`0` 表示空位 |
| `[9]` | 重复次数 |

**修饰键位图**：

| 位 | 键 | 值 |
|---|---|---|
| 0 | 左 Ctrl | `0x01` |
| 1 | 左 Shift | `0x02` |
| 2 | 左 Alt | `0x04` |
| 3 | 左 GUI（Command / Win） | `0x08` |
| 4 | 右 Ctrl | `0x10` |
| 5 | 右 Shift | `0x20` |
| 6 | 右 Alt | `0x40` |
| 7 | 右 GUI | `0x80` |

可任意按位或：`⌘+Shift` = `0x0A`，`Ctrl+Shift+Alt` = `0x07`。

**执行语义**（固件实际行为）：

1. 发一次"按下"报告（修饰键 + 6 个键码）；
2. 若 `[2] != 0`，延时 `[2] × 10 ms`，再发一次全 `0` 的"抬起"报告；
3. 若 `[2] == 0`，**不抬起**——按键会一直按住，直到你发一条"全 0"的键盘帧释放它。

> 这一步很关键：`FF 01 00 00 00 00 00 00 00 00 00 FE` 就是"抬起所有键"。
> 组合键（如 `⌘+H`）建议 `[2] = 0x0A`（100 ms），太快可能被系统丢掉。

**键码表**（HID Usage ID，十进制/十六进制都常见，这里给十六进制）：

| 键 | 码 | 键 | 码 | 键 | 码 |
|---|---|---|---|---|---|
| a–z | `0x04`–`0x1D` | 1–9 | `0x1E`–`0x26` | 0 | `0x27` |
| Enter | `0x28` | Esc | `0x29` | Backspace | `0x2A` |
| Tab | `0x2B` | Space | `0x2C` | `-` | `0x2D` |
| `=` | `0x2E` | `[` | `0x2F` | `]` | `0x30` |
| `\` | `0x31` | `;` | `0x33` | `'` | `0x34` |
| `` ` `` | `0x35` | `,` | `0x36` | `.` | `0x37` |
| `/` | `0x38` | Caps Lock | `0x39` | F1–F12 | `0x3A`–`0x45` |
| PrintScreen | `0x46` | ScrollLock | `0x47` | Pause | `0x48` |
| Insert | `0x49` | Home | `0x4A` | PageUp | `0x4B` |
| Delete | `0x4C` | End | `0x4D` | PageDown | `0x4E` |
| Right | `0x4F` | Left | `0x50` | Down | `0x51` |
| Up | `0x52` | NumLock | `0x53` | 小键盘 ÷ × − + | `0x54`–`0x57` |
| 小键盘 Enter | `0x58` | 小键盘 1–9 | `0x59`–`0x61` | 小键盘 0 | `0x62` |
| 小键盘 `.` | `0x63` | Menu（应用键） | `0x65` | | |

> **完整表**见 USB-IF《HID Usage Tables》1.12 §10 **Keyboard/Keypad Page (0x07)**：<https://www.usb.org/sites/default/files/documents/hut1_12v2.pdf>。本项目只用到上表这些。
>
> ⚠️ **修饰键不要塞进键码数组**：`0xE0`–`0xE7`（左/右 Ctrl、Shift、Alt、GUI）要用 `[1]` 的位图表达——HID 描述符里 6 字节键码数组的 Usage 范围只到 `0x65`。

## 三、鼠标帧（`0x02`）

| 字节 | 含义 |
|---|---|
| `[0]` | `0x02` |
| `[1]` | 按键位图：左`0x01` / 右`0x02` / 中`0x04`（可按位或） |
| `[2]` | X 位移，有符号 8 位（`0x80` = −128，`0x7F` = +127） |
| `[3]` | Y 位移，有符号 8 位（正 = 向下） |
| `[4]` | 滚轮，有符号 8 位（正 = 向上） |
| `[5]`–`[8]` | 保留，填 `0` |
| `[9]` | 重复次数 |

**执行语义**：每帧只发**一次** HID 报告，位移就是这一帧的 `dx/dy`。所以要移动一大段距离，得连续发多帧（每帧 ≤127），或者靠 `[9]` 让上位机展开多次。

> **相对坐标的后果**：设备不知道光标现在在哪。标准做法是先"归位"——连续发向右上角的位移（如 `FF 02 00 7F 7F …` 重复若干次）把光标顶到角落，再按已知的像素距离相对移动。分辨率、缩放或窗口一变，这套距离就得重算。

**常用片段**：

| 动作 | 帧 |
|---|---|
| 左键按下 | `FF 02 01 00 00 00 00 00 00 00 00 FE` |
| 左键松开 | `FF 02 00 00 00 00 00 00 00 00 00 FE` |
| 右键按下 | `FF 02 02 00 00 00 00 00 00 00 00 FE` |
| 中键按下 | `FF 02 04 00 00 00 00 00 00 00 00 FE` |
| 向右 16 | `FF 02 00 10 00 00 00 00 00 00 00 FE` |
| 向左 16 | `FF 02 00 F0 00 00 00 00 00 00 00 FE` |
| 向上 17 | `FF 02 00 00 EF 00 00 00 00 00 00 FE` |
| 向下 16 | `FF 02 00 00 10 00 00 00 00 00 00 FE` |
| 滚轮向上 1 | `FF 02 00 00 00 01 00 00 00 00 00 FE` |
| 滚轮向下 1 | `FF 02 00 00 00 FF 00 00 00 00 00 FE` |
| 归位到左上角（每帧 −127,−127） | `FF 02 00 81 81 00 00 00 00 00 00 FE` ×N |

> 注意：上面"归位"用的是 `0x81`（−127），重复到光标不再移动为止；有的上位机用 `0x7F/0x7F` 归到右下角，取决于流程写法。

## 四、蜂鸣器帧（`0x03`）

| 字节 | 含义 |
|---|---|
| `[0]` | `0x03` |
| `[1]`–`[9]` | 忽略 |

效果：翻转一次 LED，蜂鸣器响 **30 ms**。常用于流程节点提示音。

例：`FF 03 00 00 00 00 00 00 00 00 00 FE`

## 五、`[9]` 重复次数：谁在用它

**固件不读 `[9]`。** 键盘与鼠标的处理函数只用到 `[0]`–`[8]`。

`[9]` 是**上位机侧**的语义：网页助手在把你的流程翻译成串口帧时，对同一帧按重复次数展开成多次发送（中间自己加间隔）。所以：

- 自己写脚本直接发串口时，`[9]` 填什么都行，**要重复就自己多发几帧**；
- 用网页助手时，`[9]` 才是"重复 N 次"。

## 六、节奏与丢帧（重要）

1. **单缓冲**：固件只有一个接收包缓冲。上一帧还没被主循环处理完，新一帧就把缓冲覆盖掉——**连发必丢**。
2. **阻塞**：键盘的按住时长用 `HAL_Delay` 实现，最长 `255 × 10 ms = 2.55 s`。这期间主循环不处理新命令。
3. **建议**：每帧之间留出 ≥ 命令本身的耗时（按住时长）+ 20–50 ms 余量。网页助手内部已经做了节流；自己写脚本时要自己加。
4. 若需要确认执行完成，可以读回显帧（同 10 字节）。
5. **指针灵敏度会被"启动状态"影响**：目标机重启时**是否插着设备**，会改变鼠标的点分辨率（指针加速度）。要让相对位移可复现，建议固定成"**不插设备重启**"。——这条来自作者当年的开发备忘（[development-notes.md](development-notes.md) 第六节）。

## 七、完整示例

**按一次 `⌘+H`（100 ms）**：

```
FF 01 08 0A 0B 00 00 00 00 00 00 FE
└─ └─ └─ └─ └─ 键码 0x0B = 'h'
│  │  │  └─ 按住 0x0A × 10ms = 100ms
│  │  └─ 修饰键 0x08 = 左 GUI(⌘)
│  └─ 键盘命令
└─ 帧头
```

**输入 "hi"**（两帧，中间留间隔）：

```
FF 01 00 0A 0B 00 00 00 00 00 00 FE
FF 01 00 0A 0C 00 00 00 00 00 00 FE
```

**左键单击**（按下 + 松开）：

```
FF 02 01 00 00 00 00 00 00 00 00 FE
FF 02 00 00 00 00 00 00 00 00 00 FE
```
