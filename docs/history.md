## 二、32 个工程版本

当时每改一版就在 CubeIDE 工作区里新建一个带时间戳的工程，**本仓库只保留每代的最终版源码**，其余版本未收录（工作区里仍在，但不随开源发布）。

> 这套"每版留档"的做法有个具体流程（关 IDE → 复制目录 → 改名 → 改 `.ioc` 里的项目名 → 删 `.launch`/`Debug` → 重新导入），作者当年记在开发备忘里，已整理到 [`development-notes.md`](development-notes.md) 第四节。

## 三、第一代 → 第二代，代码上到底改了什么

用最终版对比（`gen1-2024` vs `gen2-2025`）：

| 文件 | 行数变化 | 变化内容 |
|---|---|---|
| `Core/Src/main.c` | 452 → **529** | ① 新增**上电自检**（蜂鸣器 + 鼠标画方框 + 按截屏快捷键）② 新增蜂鸣器命令 `0x03` ③ 按键分支增加到 5/6/7/10/11/12/14 ④ 键盘/鼠标处理里加了 OLED 刷新调用 |
| `Core/Key/Key.c` | 98 → **130** | 新增 **PA0 板上开关**的读取（键码 10）；原有 7 个按键与第一代完全相同 |
| `Core/Serial/Serial.c` | 284 → 284 | **无变化**：协议、波特率、收包状态机都没动 |
| `Core/oled/oled.c` | 621 → 621 | **无变化**：硬件已经没屏，代码原样保留并继续编译 |
| `USB_DEVICE/`、`Middlewares/` | — | 无实质变化（复合 HID 描述符沿用第一代的手工版） |

**结论**：第二代不是重写，而是在第一代基础上做"减法（去屏）+ 加法（蜂鸣器、更多按键、上电自检）"。串口协议**两代完全一致**——所以同一份流程文件、同一个网页助手，两代都能用。

## 四、为什么没有第三代在这个仓库里

第三代换了完全不同的技术栈（ESP32-S3、蓝牙、AirPlay 投屏、MCP、AI 闭环），代码形态、目标设备、许可策略都不同，因此**独立成项目**：

- 官网：<https://jianghui1974.github.io/Quileg-HID/>
- 它也不是前两代的"升级版"，而是把"让设备以键鼠身份工作"这个内核换了个目标和通道：**从"替人点电脑"变成"让 AI 点手机"**。

## 五、遗留的坑（两代都有，未修）

1. 串口单缓冲，快发丢帧。
2. `Key_GetNum()` 与键盘按住都是阻塞实现。
3. 相对坐标 + 归位。
4. 无执行反馈。
5. 第二代 OLED 死代码。
6. 第二代上电自检（归档版不提供补丁，需自行修改源码）。

这些坑的完整分析见 [architecture.md](architecture.md)。
