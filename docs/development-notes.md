## 二、早期面包板原型（引脚与成品不同）

备忘录里还留着一份"面包板 + 最小系统"的接线，以及另一份标注"旧"的引脚表。**两者与成品不一致**，这里原样记下来，避免有人照旧图接线后不通。

**（a）面包板原型（备忘录原文）**

| 功能 | 引脚 |
|---|---|
| OLED | **PB8 / PB9** |
| 串口 | **PB10 (TX) / PB11 (RX)** |
| USB | PA11 / PA12 |
| ST-Link | PA13 / PA14 |
| 32.768 kHz 晶振 | PC14 / PC15（3、4、5、6 脚） |
| LED | **PC13** |
| 按键（可用 IO） | PB0 / PB1 / PB3 / PB4 / PB5 / PB6 / PB7 / PB12 / PB13 / PB14 / PB15 |

**（b）早期引脚表（另一份，标注"旧"）**

| 脚号 | 引脚 | 用途 |
|---|---|---|
| 2 | PC13 | LED 指示灯（**低电平点亮**） |
| 3 / 4 | PC14 / PC15 | 32.768 kHz 晶振 |
| 5 / 6 | PD0 / PD1 | 8 MHz 晶振 |
| 7 | NRST | 复位按钮 |
| 20 | PB2 (BOOT1) | 接低电平 |
| 30 / 31 | PA9 / PA10 | USART1 TX / RX → USB-串口 |
| 32 / 33 | PA11 / PA12 | USB D− / D+ |
| 34 / 37 | PA13 / PA14 | SWDIO / SWCLK → ST-Link |
| 44 | BOOT0 | 接低电平 |
| 45 / 46 | PB8 / PB9 | 外部 OLED 显示屏 |

**成品相对原型的改动**：

- OLED：`PB8/PB9` → **`PB13/PB15`**（Nano 板的 OLED 接插件 I²C 引脚）
- LED：`PC13` → **`PA8`**（原型板是 PC13 低电平点亮；Nano 板的 LED0 就是 PA8，高电平点亮）
- 串口：原型记录为 `PB10/PB11`，成品定为 **`PA9/PA10`**（Nano 板固定接 CH340X）

> 备忘录里还有两张截图可以佐证这一版原型：CubeMX 引脚图上是 `PB8/PB9 = GPIO_Output`（OLED）、`PC13 = GPIO_Output`（LED）、`PB10/PB11 = USART3_TX/RX`；时钟树截图是 HSE 8 MHz → PLL×9 → 72 MHz、USB /1.5 → 48 MHz。
>
> 也就是说：**第一代早期是在一块 2014 年的通用 STM32F103C8T6 最小系统板（LED 在 PC13、I²C 在 PB8/PB9）上飞线搭的**；成品换成 **Nano STM32 V1.1** 后，LED 变成板载 `PA8`、OLED 走板上接插件的 `PB13/PB15`、串口接板载 CH340X。板卡细节见 `hardware.md` 第一节与本文第七节。

> 为什么改：备忘录没有记录原因（推测与布线/按键占用有关，但**不作结论**）。**请以 `firmware/*/Core/` 与 `.ioc` 为准**——照旧图接线会不通。

## 三、救砖：无法通过 ST-Link 下载程序时

如果某次写入的设置（例如误关调试口、改错时钟）导致 ST-Link 连不上，按下面走一遍：

1. **BOOT0 跳线置 1**（高电平）；
2. 按下**复位** —— STM32 进入系统 Bootloader，不再执行用户代码；
3. 打开 **STM32CubeProgrammer**，选 `ST-LINK` 模式连接；
4. 在 **Full chip erase** 选项卡执行**全片擦除**；
5. 关闭连接；
6. **BOOT0 恢复 0**，按复位；
7. 回到 STM32CubeIDE，重新写入正确的程序。

> 全片擦除会清掉芯片里所有内容（包括原来的程序），这是"救回来"的代价。

## 四、创建项目副本（32 个时间戳工程的由来）

当年每改一版就复制一份工程留档，所以工作区里堆了 32 个 `go_mouse_keyboard_<时间戳>`。备忘记录的流程是：

0. 关闭 STM32CubeIDE
1. 拷贝目录到新文件夹
2. 把文件夹改名为新项目名
3. 把 `xxx.ioc` 改名为 `新项目名.ioc`
4. 打开该 `.ioc`，查找旧项目名并替换成新项目名 —— 至少两处：
   ```
   ProjectManager.ProjectFileName=go_mouse_keyboard_202407192201.ioc
   ProjectManager.ProjectName=go_mouse_keyboard_202407192201
   ```
5. 删除 `xxx.launch`
6. 删除 `Debug` 目录
7. 打开 STM32CubeIDE
8. 左侧项目列表**右键 → 导入**
9. 选择 `General → Existing Projects into Workspace`
10. 选择目录
11. **取消**勾选 `Copy projects into workspace`
12. 点击 `Finish`

> 备忘录在"修改项目缺省目录 → properties →"处截断，后续步骤没有记录。
> 本仓库只保留两代最终版；如果你要复刻这套"每版留档"的习惯，按上面 12 步即可。

## 六、其它两条经验

1. **`usbd_hid` 必须手工替换**：键盘鼠标一体化后，由 `.ioc` 自动生成的 `usbd_hid.h/.c`（位于 `Middlewares/ST/STM32_USB_Device_Library/{inc,Src}`）需要手工修改或直接替换。备忘录记的大小是 `usbd_hid.h` 约 3 KB、`usbd_hid.c` 约 24 KB —— 与仓库里 `firmware/reference/usbd_hid-override/` 的 3,180 B / 23,579 B 一致。
2. **指针灵敏度与启动状态有关**：目标机重启时**是否插着设备**会影响鼠标的"点分辨率"（指针灵敏度）。要让流程可复现，统一成"**不插设备重启**"。

## 关于 OLED

第一代的屏是 **0.96 英寸 128×64，型号 `ZJY096I0400WG01`，中景园**。驱动 IC 属于 **SSD1306 系列**——`oled.c` 的初始化序列可以佐证：

- `0xA8, 0x3F` 多路复用率 64
- `0xDA, 0x12` COM 引脚配置（128×64 常见值）
- `0x8D, 0x14` 开启电荷泵
- `0x20`（页寻址）未显式设置，用默认页寻址 + `0xB0|page` / `0x10|col` 定位

接法是软件 I²C：`PB13`=SCL、`PB15`=SDA（早期原型接在 `PB8/PB9`）。亮度、视角等其他参数以中景园的数据手册为准，本仓库不附厂商资料。
