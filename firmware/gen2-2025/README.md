# 第二代固件（2025-07）

**原始工程名**：`go_mouse_keyboard_202507251525`（2025-07-25 15:25 定稿，第二代最后一版）
**开发环境**：STM32CubeIDE 1.18.1 工作区

## 这是什么

与第一代同一套内核：STM32F103C8T6 + USB HID 复合键鼠 + 9600 串口 12 字节命令帧。

本代的硬件变化：**去掉 OLED 屏**，**新增蜂鸣器**（PA4），新增 **PA0 板上开关**（内部测试用）。原有 7 个按键（PB5/PB6/PB7/PB10/PB11/PB12/PB14）两代相同。

## ⚠️ 上电自检（必读）

本代固件在**每次上电**时执行一段调试遗留的演示：

```
蜂鸣器响两声 → 鼠标画一圈方框 → 按 ⌘+Shift+3（macOS 截屏）+ 安卓截屏组合键 → 响三声
```

插到 Mac 上会**真的截一张图**。归档版**不提供补丁**（保持最终源码原样）；要关掉的话，自行把 `Core/Src/main.c` 里那段演示调用（`processMouseCommand(...test_2)` 到 `processKeyboardCommand(...test_6)`）注释掉或用 `#if 0` 包住，重新编译即可。

## 编译与烧录

见 [`../../docs/build-and-flash.md`](../../docs/build-and-flash.md)。**若从 `.ioc` 重新生成过代码，必须用 `../reference/usbd_hid-override/` 覆盖 `usbd_hid.c/.h`**，否则只会出现键盘或鼠标其中一个。

## 想改的话

最值得做的三件事（按性价比）：

1. 把 `Core/oled/` 移出编译并删掉 `OLED_*` 调用（省掉每条命令的 I²C 开销）。
2. 把上电自检做成 `#ifdef SELFTEST` 编译开关。
3. 键盘按住改成非阻塞（用 SysTick），这样长按期间还能收命令。
